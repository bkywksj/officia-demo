🔴 产物需用 Adobe Acrobat 打开才看得到效果——浏览器内置阅读器多数不验证签名。 测试台用的是现场生成的自签名证书，会提示"签署人身份未知"，但"文档未被修改"仍为绿； 消除该提示需私有 CA 或公共 CA 证书。三人会签走增量更新，前面每个人的签名都不失效。
验证签名不需要 Acrobat——OfficiaPdf.verify 直接给出结构化结论，业务系统可据此程序化判定。篡改演示会把签名件的正文改掉 一个字节再验一次，改动前后结论一正一反，是"防篡改"最直观的证明。
推荐流程：先数字签名或三人会签 → 把产物重新上传 → 验证签名 → 篡改演示。
